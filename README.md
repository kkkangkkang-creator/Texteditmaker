# Texteditmaker

Side Story의 **말하기**를 붙여 넣고, 같은 카드 디자인으로 확인한 뒤 **티스토리용 HTML**을 복사하는 브라우저 도구입니다.

## 사용법

1. `index.html`을 내려받아 브라우저로 엽니다. 설치나 API 키는 필요 없습니다.
2. Side Story 말하기의 카드 복사 또는 전체 복사 버튼으로 가져온 내용을 붙여 넣습니다.
3. 미리보기에서 카드와 속마음을 확인합니다. 테마, 포인트 색, 본문 글꼴·크기, 카드 너비를 바꿀 수 있습니다.
4. **티스토리 HTML 복사**를 누릅니다.
5. 티스토리 글쓰기의 **HTML 모드**에 붙여 넣고, 발행 전 티스토리 미리보기에서 확인합니다.

**HTML 파일 저장**은 독립 실행되는 카드 문서를 저장합니다. 사이트 자체도 `index.html` 하나로 동작하므로 로컬 파일 또는 정적 호스팅에서 사용할 수 있습니다.

### GitHub Pages에서 사용

저장소 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)**를 선택하고 저장합니다. GitHub가 배포를 완료한 뒤 Pages 화면의 주소로 접속합니다. 이 저장소의 파일들은 루트에서 바로 서비스하도록 구성되어 있습니다.

## 입력 형식

- Side Story의 기존 복사 기능이 만드는 `**요청**` / `**요청 1**` / `**속마음**` Markdown
- Side Story의 `.md` 저장 내용을 복사한 텍스트
- `<sideb-response><request>…</request><spoken>…</spoken><inner>…</inner></sideb-response>` 원문. 여러 블록과 마지막 미완료 블록도 인식합니다.
- 일반 텍스트는 질문 없는 답변 카드 한 장으로 표시합니다.

전체 카드 복사는 요청 표제와 빈 줄을 기준으로 질문과 답변을 나눕니다. **질문 자체에 빈 문단이 있거나 본문에 동일한 표제가 등장하면 기존 Markdown 복사 형식만으로는 구분이 모호할 수 있습니다.** 이때는 태그 원문을 사용하세요. 본문 내부의 `---` 구분선은 보존합니다.

## 카드와 티스토리 호환

기본 모양은 [ST-Sidestory](https://github.com/kkkangkkang-creator/ST-Sidestory)의 `speakCards()`와 `.speak-news-*` 디자인을 기준으로 재구성했습니다. 일반 텍스트 클립보드에는 Side Story에서 선택한 색상·글꼴 설정이 없으므로 그 설정을 자동으로 추출하지는 않습니다. 이 도구에서 선택한 설정이 미리보기와 HTML에 함께 적용됩니다.

- **한 장씩 넘기기**: HTML radio와 범위를 제한한 CSS를 사용합니다. JS 없이 이전·다음 카드로 이동합니다. 키보드에서는 라디오 입력에 초점을 두고 방향키로 이동할 수 있습니다.
- **모든 카드 펼치기**: 모든 질문·답변을 세로로 표시합니다.
- **속마음**: 기본 HTML `details`로 접고 펼칩니다. 포함 여부·기본 펼침을 선택할 수 있습니다.
- 카드 스타일 대부분은 인라인으로 넣고, 카드 넘기기·모바일 너비·속마음 장식만 고유 ID 아래의 CSS로 제한합니다. 한 글에 여러 결과물을 넣어도 다른 카드나 스킨에 CSS가 퍼지지 않습니다.
- 내보낸 카드에는 JS, iframe, 외부 폰트·라이브러리 요청이 없습니다. 글꼴은 기기에 설치된 글꼴을 사용합니다.
- 미리보기는 스크립트가 차단된 sandbox iframe에서 실행합니다. 입력 HTML의 임의 스타일·스크립트·이미지·링크를 실행하지 않으며, Markdown과 허용한 기본 인라인 서식만 표시합니다.
- 티스토리 에디터나 스킨이 `style`, `input`, `details`를 변경·제거할 수 있으므로 실제 티스토리 미리보기에서 확인하세요. 접기·넘기기가 유지되지 않으면 **모든 카드 펼치기 + 속마음 처음부터 펼치기**로 내보내세요. HTML을 넣은 뒤 일반 편집 모드로 전환하면 코드가 바뀔 수 있습니다.

입력은 브라우저 메모리에서만 처리하며 저장하거나 서버로 보내지 않습니다. 새로고침하면 입력 글은 지워집니다. 자동 복사가 막힌 브라우저·로컬 파일에서는 코드가 선택되어 수동 복사가 가능합니다.

## 개발

Node.js 18 이상에서 `npm test`로 파싱·출력·입력 안전성 검사를 실행합니다. 별도 의존성 설치는 필요 없습니다. 로컬 서버가 필요하면 `npm run dev`를 사용합니다.
